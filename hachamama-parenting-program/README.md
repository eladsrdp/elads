# תוכנית ליווי החממה — WhatsApp Companion לקורס הנחיית הורים

מערכת עצמאית (מחליפה Airtable) לליווי דיגיטלי של נרשמים לקורס הנחיית הורים: כל נרשם מתקדם בקצב אישי, מקבל הודעות WhatsApp יומיות לפי תוכן מוגדר מראש, השליחה עוברת דרך Make.com (מחובר ל-WhatsApp Business Platform הרשמי). כולל שאלונים/טפסים ודשבורד קריאה-בלבד למנחות מנטוריות.

פרויקט זה עצמאי לחלוטין ואינו קשור לצוות הסוכנים (יעל/יובל/חן/נועה) המתועד ב-CLAUDE.md הראשי של הריפו.
