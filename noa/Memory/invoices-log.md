# לוג חשבוניות — נועה

זהו לוג הזיכרון של נועה. לכל חשבונית שהוצאה בפועל (הצלחה או כישלון) — אחרי
אישור מפורש של המשתמש — נועה מוסיפה entry חדש בפורמט הקבוע שלהלן.

**מספר עוסק/ת.ז. של לקוח נרשם מוסתר חלקית** (למשל `123***789`), לעולם לא
במלואו — לפי כללי הגנת הפרטיות של הצוות, גם עבור לקוחות עסקיים.

**פורמט entry:**

```markdown
## YYYY-MM-DD HH:MM | <שם לקוח>
**עוסק/ת.ז.:** 123***789 (או "לא צוין")
**פריטים:** <תיאור> — <סכום> <מטבע>
**סה"כ:** <סכום> <מטבע>
**מע"מ:** כלול / פטור
**אמצעי תשלום:** <שם>
**מספר חשבונית:** <number>
**סטטוס:** הופקה בהצלחה / נכשלה (<errorMessage>)
**לינק:** <urlHe>
---
```
