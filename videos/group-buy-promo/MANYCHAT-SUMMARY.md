## תמונת מצב

חשבון ה-ManyChat של ארץ-קיר מנהל בוואטסאפ את כל מחזור החיים של "קבוצת רכישה": מארגן פותח קבוצה ביישוב שלו, מקבל הודעת שיווק מוכנה + קוד קופון, השכנים קונים ב-160 ש"ח במקום 229, והמערכת מלווה את כולם עד איסוף המשחק ואחריו.

## ארכיטקטורה

&#91;embedded content: ארכיטקטורה · ManyChat + Make\]

ManyChat מחזיק את השיחה (תבניות, שאלות, כפתורים), ו-Make מחזיק את הלוגיקה העסקית. שני הכיוונים: כפתור ב-ManyChat שולח בקשת HTTP ל-Webhook של Make (עם נתוני איש הקשר) ומקבל בחזרה שדות כמו קישור, קוד קופון ושם; ו-Make מפעיל דרך ה-API את האוטומציה המתאימה לשלב של הקבוצה.

שדות מרכזיים: ישוב, קוד קופון, קישור, שם, כמות הזמנות, רשימת מזמינים, כתובת, שם/טלפון ראש קבוצה, מספר משלוח, שם רוכש/מקבל (מתנה), שם/מייל/יעד/לינק שגריר. תגיות מסמנות אילו הודעות נשלחו (תגית לכל שלב) ואילו קמפיינים כבר התקבלו.

## ערוצי כניסה ותהליכים נוספים

מעבר למסע הקבוצה יש ארבעה תהליכים עצמאיים: משפך מילת מפתח לציבור החרדי, הרשמת שגרירים, מסלול מתנה, והגדרות מערכת.

### אוטומציות חרדים (LIVE, 583 הפעלות, CTR 89.6%)

טריגר: הודעה שמתחילה ב-"אנחנו רוצים ארץ קיר" (מגיעה מפרסום עם קישור וואטסאפ).

1. תמונה + הסבר מותאם שפה ("מפת ענק של ארץ הקודש") וכפתור **בטח!**
2. הצעה: 199 ש"ח כולל שליח לבית, או משחק במתנה למי שמארגן רכישה משותפת. כפתורים: **לרכוש באופן אישי** / **לארגן רכישה משותפת**.
3. רכישה אישית ← הודעה עם כפתור קישור לדף רכישה.
4. רכישה משותפת ← הסבר ב-3 צעדים (מינימום 6 משחקים, 160 ש"ח למשחק) ← שאלה "באיזה ישוב אתם גרים?" (נשמר לשדה ישוב) ← "מה שם המשפחה?" (שדה שם) ← "כבר שולחים לכם הודעה מוכנה" ← שמירת טלפון + קריאת Make שפותחת את הקבוצה (קופון + קישור).

"אוטומציות חרדים — הודעה להפצה" שולחת למארגן את תבנית 2ut1.haredim: נוסח פרסום מותאם לציבור החרדי ("הבעל"ט", "ארץ אבותינו"). הטריגר שלה כבוי.

### שגרירים (תהליך חדש, ספטמבר 2026)

- **יצירת שגריר** (LIVE, מילת מפתח בדיקה "טסט חובב הדסטארט") — 3 שאלות: שם, מייל, יעד סכום ← "רק רגע..." ← קריאת Make שיוצרת לינק אישי.

## רעיונות לסרטון

הסיפור החזק: משפחה אחת פותחת קבוצה ביישוב, ומשם כל השאר קורה לבד בוואטסאפ — עד שהמשחק על הדלת.

1. **פתיחה (0:00–0:10)** — "כמה הודעות צריך כדי לנהל 7,000 רוכשים במאות קבוצות רכישה? אפס ידניות."
2. **פתיחת קבוצה** — מסך טלפון: מסע החרדים (שאלת ישוב ← שם משפחה ← הודעה מוכנה עם קופון אישי תוך שניות). להראות ש-Make מייצר קופון וקישור ברקע.
3. **כל רכישה מעדכנת את המארגן** — "גם משפחת X מתמגנטת בזכותך, עד עכשיו N משחקים" (7,760 הפעלות). גימיפיקציה שמניעה לפרסם עוד.
4. **הקבוצה נתקעה?** — הודעה עם 3 כפתורים (לפרסם שוב / לקנות / לבטל), וכל בחירה מפעילה תהליך מלא כולל זיכויים.
5. **משלוח בדרך** — מספר מעקב שנכנס אוטומטית להודעה.
6. **רגע השיא: כפתור "אספתי!"** — המארגן מקבל רשימת מזמינים, כל רוכש מקבל כתובת איסוף, לוחץ אספתי — ומיד מקבל תוכן המשך (משחק אינטרנטי, קהילה). CTR 60.6% ו-41.6%.
7. **מעבר לקבוצה** — מסלול המתנה עם השולח הסודי ("ציפור קטנה לחשה..."), שגרירים עם יעד ומד התקדמות.
8. **סגירה** — מספרים: 14,245 אנשי קשר, 35 אוטומציות, 93%–99% מסירה ב-Broadcasts.

לפני צילום מסך: לטשטש שמות ומספרי טלפון של אנשי קשר, לא להציג כתובות Webhook של Make, ולהדגים עם איש קשר דמה (משפחת ישראלי).
