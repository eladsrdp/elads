# Priority Lite — ממשק קל לדיווחי שעות ומשימות מעל Priority ERP

## Overview
אפליקציית web ‏(PWA, עברית RTL) בתיקייה `priority-lite/` שעוטפת את Priority ERP בממשק מהיר: טיימר, דיווחי שעות ידניים, סיכומים (יום/שבוע/חודש לפי פרויקט→משימה), וחיפוש משימות. ארכיטקטורה: monorepo ‏(npm workspaces) עם `shared/` (טיפוסים), `server/` (Hono + Supabase, אימות OTP במייל לפי whitelist טלפונים, JWT cookie ל-7 ימים, adapter מבודד מול Priority OData עם mock לפיתוח), ו-`client/` (React 19 + Vite 8 + Tailwind v4 + Dexie). דיווחים נשמרים כטיוטות מקומיות ונשלחים לפריוריטי רק אחרי אישור המשתמש (תוצאה פר-פריט, שגיאות עם retry). שכבת actions עם zod schemas מוכנה לחיבור צ'אט-LLM בשלב 3. **סטטוס: בפרודקשן ב-Vercel** (`priority-lite-one.vercel.app`) — PRIORITY_MODE=real, EMAIL_MODE=resend, aiEnabled. Vercel Build Output API עם esbuild CJS bundle; `api-src/index.ts` מייצא `getRequestListener(app.fetch)` כ-Nodejs handler. כתיבה לפריוריטי עובדת ואומתה E2E. **ניהול משימות Phase 1 — מומש ומוזג ל-main (2026-08-18)**: הרחבת "משימות לקוח" (CUSTNOTESA) לניהול משימות מלא — יצירה/עדכון/סטטוס/העברה בין אנשי צוות/חיפוש גלובלי/"המשימות שלי"/היסטוריית סטטוס. כל 17 המשימות מהתוכנית מומשו, נבדקו, נסקרו (spec+quality, כולל ביקורת סוף-branch מלאה), ומוזגו ל-`main` דרך PR #1 (merge commit `3898e69`). **אומת חי מול Priority אמיתי (2026-08-18)**: יצירה/סטטוס/עדיפות/תאריך/"לטיפול"/היסטוריה — עובדים. **תיאור משימה (`description`) שבור מול Priority אמיתי** — השדה read-only בפריוריטי עצמה, לא ניתן לתיקון בקוד שלנו; דורש החלטת מוצר (ראה Open Questions). **ניהול משימות Phase 2 — מומש ומוזג ל-main (2026-08-19)**: צ'קליסטים אישיים וטיוטות חופשיות, לא מסונכרנים עם פריוריטי בשום צורה (לא קוראים ולא כותבים ל-adapter בכלל), פרטיים למשתמש (אין שיתוף בין עובדים), נשמרים ב-Supabase (2 טבלאות חדשות: `local_checklist_items`, `local_drafts`) לגישה בין-מכשירים. כל 13 המשימות מהתוכנית מומשו ונסקרו (spec+quality); נמצאו ותוקנו 2 באגים אמיתיים בסקירה (כפילות מזהים ב-reorder דורסת sort_order; rollback במערך שלם ב-UI יכול לדרוס מוטציה מקבילה מוצלחת — אותה משפחת באג שכבר תוקנה פעם ב-TaskDetail, כאן עם אותו פתרון `savingRef`). **טבלאות Supabase נוצרו בפועל בפרודקשן ואומתו (2026-08-19)** — הפיצ'ר אמור לעבוד בפרודקשן. **טרם נבדק ידנית בדפדפן** — ראה Open Questions.
