# Make Issues Dashboard — webhook receiver + triage dashboard ל-Make.com

## Overview
מערכת עצמאית חדשה בתיקיית `make-issues/` (לא קשורה לחמשת סוכני התוכן) — מקבלת webhooks מ-Make.com כשסנריו נכשל (client name, scenario name, תיאור, סוג תקלה מתוך 4 קבועים, קישור לסנריו, קישור לריצה), ומציגה אותן בלוח בקרה מוגן-login שהמשתמש משאיר פתוח על מסך שני. סימון "טופל"/"להתעלם" מעלים את התקלה מהמסך הראשי ומעבירים אותה למסך "היסטוריה". ארכיטקטורה זהה ל-`priority-lite/` (Hono+React+Vite+Tailwind, monorepo npm workspaces, Vercel Build Output API). Auth: username+password (bcrypt), JWT access token קצר (שעה) + refresh token מסתובב (30 יום, `userId.secret` split — רק ה-secret נשמר כ-hash). Rate limiting על login דרך DB (לא זיכרון-תהליך, בגלל Vercel serverless). Webhook מאומת ב-shared-secret (constant-time compare), URLs חייבים https בלבד (מניעת stored-XSS). לוח הבקרה: toggle כרטיסים/טבלה (persisted ב-localStorage), רענון אוטומטי כל 15 שניות.

שכבת DB עם 4 מימושים ל-interface אחיד (`AppDB`): `memory-impl` (בדיקות), `local-impl` (קובץ JSON מקומי, לפיתוח בלי ענן), `supabase-impl`, `neon-impl` (Postgres serverless דרך `@neondatabase/serverless`, ה-tagged-template `sql`). בפועל בפרודקשן: **Neon**, לא Supabase — המשתמש דחה את Supabase במפורש בגלל היסטוריית auto-pause כואבת ב-priority-lite (ראו [[priority-lite-app]]). עדיפות ב-`createDb()`: `DATABASE_URL` (Neon) > Supabase creds > local file.

**סטטוס: בפרודקשן, חי ב-Vercel** (`make-issues.vercel.app`), משתמש ב-Neon אמיתי, נבדק E2E מלאה כולל בדפדפן על ה-URL החי (login → webhook → poll מציג תקלה → resolve → היסטוריה). Webhook endpoint ל-Make.com: `https://make-issues.vercel.app/api/webhook/issues` (secret ב-`WEBHOOK_SECRET`, לא ב-vault הזה — נמסר למשתמש בצ'אט).

## Open Questions
- **אין אכיפת תוקף בצד-שרת ל-refresh token** — רק `maxAge` של העוגייה בדפדפן מגביל; טוקן גולמי שדלף ומשוחזר דרך Cookie מזויף (לא דרך הדפדפן) יישאר תקף עד רוטציה/logout הבאים. הוחלט כפשרה מקובלת לכלי פנימי ל-3-4 משתמשים ותועד ישירות בקוד (`tokens.ts`) — לשקול מחדש אם ההיקף יגדל.
- **המשתמש עדיין לא חיבר בפועל את ה-Error Handler-ים ב-Make.com** לתקלות ה-webhook — זה תלוי בו, לא בקוד.
- **חשבונות משתמש**: כרגע רק `elad`/`change-me` (חשבון בדיקה) זרוע ב-Neon דרך `npm run seed`. עוד 2-3 עמיתים צריך להוסיף ל-`accounts.json` (לא ב-git) ולהריץ seed שוב.
- **אין מנגנון איפוס סיסמה עצמי** — reset ידני בלבד (admin מריץ UPDATE ישיר או `npm run seed` מחדש), החלטה מכוונת לכלי קטן.
- `.claude/launch.json` בשורש הריפו מכיל עכשיו entry בשם `make-issues` (מיישר עם priority-lite/cashflow) לצורך preview מקומי.
